# Study and historical authoring tools

These are study drivers and reporting helpers, not another vector renderer. The current frozen pilot is documented in [the research index](../docs/research/README.md).

| Group | Entry points | Role |
| --- | --- | --- |
| Prepare | `prepare_process_pilot.py` | Freeze inputs, create trial roots, and establish the method manifest |
| Build | `process_host.py` | Isolated sequential builder session with shared timing and batch accounting |
| Compare | `prepare_blind_comparisons.py` | Prepare neutral later comparisons; does not manufacture preferences |
| Edit | `prepare_edit_tasks.py`, `edit_host.py` | Separate standardized editing evaluation, still pending |
| Report | `collect_process_results.py`, `assess_process_pilot.py` | Gather records and assess actual supplied comparison evidence |
| Briefs | `briefs31/`, `briefs32/` | Historical release briefs and current three-genre pilot briefs |

The authoring checkout also retains earlier `*31.py`, `focused_forward.py`, and artwork-specific drawing/repair helpers. They document previous runs and may not be part of the sanitized public distribution. They are not current installation instructions; do not rerun them to recreate missing evidence. Their files stay in place to preserve history and frozen paths.

The remaining eight attempts are deferred. Do not change frozen host helpers, inputs, limits, or the protocol during this documentation cleanup. Recorded failures stay in the denominator. A later implementation repair receives a new method identity.
