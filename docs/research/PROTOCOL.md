# Preregistered staged pilot protocol

Draft prepared 13 October 2026. Freeze input hashes, code commit and builder environment before first held-out build. The frozen JSON manifest is authoritative for the actual experiment; this draft does not claim production has begun.

The three fresh briefs are in benchmarks/briefs32: Exchange Night poster; cooperative bicycle tyre repair; fictional library decision graphic. The campus/community settings are a restricted domain. Repeated builds and judgments remain correlated within each brief. Historical release briefs are calibration tasks only.

Retrieve prior Design Brain guidance once before freezing: reference-to-decision reasoning, intended-size contours, and diagram material anchors. Supply the same paraphrased common-context.md to every condition, with source-note hashes in context-provenance.json. Mutable vault retrieval and new calibration/pilot feedback are excluded during held-out builds. Builders retain lessons locally; the parent aggregates them after all eighteen builds. This is not a memory-transfer experiment.

Conditions are designer-v1, layout-blockout-v1 and designer-process-v1. Two fresh sequential builder contexts per brief/condition produce 18 outputs. Existing default is the strong same-host/native-editor comparison. No weak single-shot baseline replaces it. This pilot tests the entire process; it does not separately isolate focused acceptance, graphs, enforcement, or memory retrieval. Close external systems are related work, not invented experimental baselines.

All builders receive the same frozen reference pack, vocabulary and production requirements; references reused from prior research are labeled cached and actually re-inspected. Seven available cached works are below the broader 15–25 target. Reference reuse, restricted domain and model-context reviewers constrain conclusions. No external interviews or claims of new source access are fabricated.

Match inherited host model/settings, image-tool access, canvas/use size, locked copy and budget. Record the actual model identifier when available; do not infer it from an account default. Native vectors remain final. An optional host image study is permitted equally across conditions and consumes active build time; disclose its actual use.

The current chat turn metadata records `gpt-6.1-sol`, reasoning effort `high`. Builders use inherited settings without overrides. Record builder/reviewer contexts and verify their returned environment metadata when exposed; a missing per-agent receipt is a provenance limitation, not permission to invent a measured identity.

Limits: 60 active minutes, 24 planned batches including studies/pilots/corrections, three final correction rounds and two non-improving stop rule. Pause only for independent review waiting; report it separately. An exhausted build is preserved and reported without automatic rebuilding. The adapter records host tool calls; internal native recovery/render queries are not the same metric. Unavailable token telemetry is reported as unavailable. Honest host use of the adapter is part of the trust model, not a secure sandbox against arbitrary code.

The operational time allowance is wall elapsed from the adapter start less explicit independent-review pauses, including planning and host processing. Wall and monotonic timestamps are recorded prospectively for diagnostic comparison. Suspension is not silently deducted, and an undiagnosed timing gap is disclosed as disruption. Only the frozen method and input pack apply to pilot builders; locked code files are checked before host calls. A code change during a pilot requires a separately identified study, not retroactive protocol replacement.

For the held-out pilot, the shared ledger starts immediately before fresh builder dispatch, so pre-session research/planning and initialization also consume the allowance. Local Session startup timing is secondary; the shared ledger governs the trial. Calibration timings start at local Session creation and are not directly compared with holdouts. Report instrumented adapter calls separately from initialization/restore, internal native recovery and post-build read-only verification; their counts are not a complete native-command or token cost measure.

Freeze schedule and anonymous mappings before evaluations. Evaluation packets show locked brief, anonymous full/use images and sanitized native structure, excluding condition, target, creator rationale, scores and history. Construction reviewers use the normal target contract; final cross-condition judges receive common-brief evidence only. Counterbalance comparison positions across the twelve full-vs-default/full-vs-blockout pairs. Retain both repeats, all failures, disagreements and missing evidence. Do not feed pilot findings into later builds or claim post-hoc winners were preregistered.

Primary: common-brief preference and consequential defects. Secondary: communication, typography/layout/color/imagery/cohesion/distinctiveness, editability, exact copy, production failures and cost. Do not collapse these into a professional-quality score. After building, apply the brief's same standardized edit task to separate copies with equal 10-minute/4-batch allowances and inspect retained interaction/association and unintended changes. Failed/missing source artworks are reported, not silently excluded.

Editing contexts receive anonymous native copies, original full/use images and the common brief/task, without construction graphs, scripts, creator history or condition labels. Editing order is seeded separately. Use EditSession for scoped quick edits and preserve originals. Record source/final native hashes, tool receipts, actual before/after views, affected IDs and unchanged-neighbor evidence. The editor's scope verdict and a later independent observed assessment are separate; a failed/missing edit is retained among all18 attempted task units.

Operational gate: both fresh specialists and the owner's blind preference agree on clear improvement over default in >=4/6 matched pairs spanning >=2 genres, with no consequential regression in the remaining pairs. Report blockout comparisons separately. This is a release decision rather than a statistical population claim. With three independent briefs, do not report conventional significance as proof of broad superiority; present brief-level paired outcomes and descriptive uncertainty.

The owner is the only initial human evaluator. Prepare a later designer/reader panel, relevant comprehension tasks, order-swap reliability checks and recruitment/consent protocol; obtain institutional review when applicable before conducting that study. No human panel, comprehension improvement or journal-readiness result is claimed by this pilot alone.
