## Reliability and trust

Versioned files, native mappings, accepted tasks/stages and relationship checks are bound to current evidence. Known object changes invalidate incident relationships; unknown/global changes invalidate broadly. Tests exercise isolation, resume, stale evidence, mappings, failed correction and production blocking. Actual native study connections and reopen/export checks test integration separately from synthetic observations.

Image-path and hash validation cannot authenticate perception. A reviewer ID is not an independently authenticated identity. Hashes detect changes relative to stored records, and are not signed tamper-proof provenance. The host adapter records budgets and honest tool use; arbitrary code can bypass it. These trust boundaries are stated explicitly. Neither geometric proximity nor a current relation record proves meaningful contact. PDF existence and revision binding do not universally certify print production.
