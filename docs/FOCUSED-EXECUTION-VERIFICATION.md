## Actual forward test

The brief preserved an existing two-person, wordless, flat radio-repair scene while clarifying working-hand mechanics. Native size was 1536 × 1024; intended size was 768 × 512. This was a new narrower maintenance experiment, not reopening the exhausted historical run or assigning it extra correction budget. Originals and historical records were preserved.

Three cached references and three existing framing alternatives were freshly inspected. A fresh concept reviewer chose the balanced framing while explicitly reporting limited concept diversity. A historical native construction pilot was re-inspected and rebound to the current specification; it was not advertised as freshly built. The test used sequential host editing, 12 planned batches, one concept reviewer and two fresh final specialists per round: nine reviewer contexts in total. They are model contexts, not independent human experts.

| Initial | Communication saw improved local wrist continuity; craft identified two arm routes converging on one hand and a consequential regression. | Untouched original |

| Correction 2 | Both preferred clearer cabinet contact, but the unchanged upper tool grip remained a consequential weakness under the maintenance brief. | Contact candidate, with unresolved findings |

The actual `revise → correction → pass` task loop was exercised before final review. Independent critique subsequently rejected a creator-confirmed local change; host task acceptance was therefore not treated as proof of aesthetic or anatomical success. The queue converted observed findings into narrow corrections, and all three permitted final correction rounds were used without resetting the budget.

The example reinforces a practical instruction now included in the skill: trace an arm/object from source to endpoint and name its working/supporting role before smoothing its contour. A single native group can contain multiple hands. Small scope metadata does not guarantee that the host has correctly understood those relationships.
