# Experimental designer process

Explicitly select full mode `layout-blockout-v1` or `designer-process-v1`; designer-v1 remains default. Record audience/message/use/style in `design_brief`, then inherited research/calibration and three meaningful `layout` alternatives with actual copy and normalized bounds.

For each alternative plan composition with `context:study`, `study_id`, `layout_id`, purposeful changes and 2–3 named checks. All native operations route to an isolated study connection. Capture full/use, actually view them, and confirm pass/revise/blocked with exact check_results and image evidence. Use close_study true after pass or explicitly abandoning blocked. Record blockout with the closed passed study ID. Studies never complete production stages. Resume restores isolated context; uncertain edits are never replayed.

Record three native blockouts, developed directions and fresh independent concept review, target/spec, then assembly action start with the selected study_id. In the full process record entity_graph: meaningful roles, spec bindings, native mappings, normalized named anchors, spatial relations and a separate acyclic dependency graph. Keep shared style and one owner per cross-component interaction. Build focal relationships before context and useful detail; split parts only when it resolves a difficulty. Trace working/supporting paths from source to endpoint before editing.

Directions IDs match layout IDs; each thumbnail matches its registered blockout bytes. actual_copy covers that study's live native text with whitespace normalized. Describe wordless copy explicitly. Concept reviewers see all three full/use previews and calibration references before production. Intended copy alone cannot stand in for different words in a rough.

Use the compact working packet. The full process inherits focused task/stage acceptance and correction queues. Record relation_check using current confirmed full/use/target and real object maps. Distance/alignment/containment are geometric diagnostics; grip/contact/association/occlusion require actual visible judgments. Geometry does not establish semantics or aesthetics. Inspect neighbors and the whole scene after local repairs. Reconcile stale graphs/mappings; unknown impacts invalidate broadly.

During a study the packet shows its goal/checks and its own full/use capture; stale or uncertain flags block reliance on it. After assembly start the selected blockout supplies the production preview until a new capture, with revision/spec freshness. These previews do not accept production tasks/stages. The declared dependency graph guides the host; the gateway does not discover useful parts or schedule all semantic construction dependencies automatically.

Keep inherited construction studies, fresh concept/final reviewers, retained-best selection, three correction rounds, originals, live text, native reopening and export inspection. Planning/construction stay sequential within each build. Only the owner's explicitly authorized experiment harness uses fresh sequential builder agents; no concurrent editing of one document. Never transfer trial feedback or lessons to later held-out builders. All pilot outputs, failures and costs must be retained. The programme has not yet established general improvement or human-quality agreement.
