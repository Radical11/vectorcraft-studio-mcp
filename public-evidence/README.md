Dated snapshots remain unchanged. Additional stage/rough evidence is published as a separate supplement with source and public hashes. Hashes bind bytes, not the truth of a visual judgment. Fixture reports, model observations, and human responses have different meanings and remain labeled.

The first public staging normalized JSON line endings and redacted paths after the snapshot's inner manifest was written. Its original values are preserved. The additive [publication audit](process-stages-20261015/publication-audit.json) records 122 affected JSON digests; the top-level public provenance manifest records actual distributed bytes. This does not change trial outcomes or native/PNG artwork bytes.

Cached third-party reference images, raw conversations, private configuration, vault notes, input archives, and recovery documents remain excluded. Asset ownership is listed in [ASSETS.md](../ASSETS.md).
