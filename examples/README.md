# Editable evaluation examples

These original creator-authored case studies use the fixed briefs in benchmarks/briefs31. The baseline routine received critique and corrections as well. Each folder contains the strongest retained reviewed native file, live-text SVG where applicable, PDF, full/use-size PNG and a neutral sanitized document inspection. The repair illustration is intentionally wordless.

Images are rendered outputs, not embedded raster substitutes in native artwork. Fonts are referenced, never bundled; install Arial and Georgia or inspect substitution on your machine. These examples do not prove general professional superiority. See docs/EVALUATION.md and public-evidence for actual observed judgments and limitations. Raw calibration and generated references are excluded.
