01 / RESEARCH

Choose an idea
worth building.

Calibrate against real references. Develop three alternatives with actual copy. Have a fresh reviewer compare them before selecting a direction.

02 / BUILD

Construct the
meaningful parts.

Test native contours first. Map the specification to editable objects. Compare full and intended-size renders with the target after each meaningful stage.

03 / CRITIQUE

Let the stronger
artwork survive.

Separate communication from drawing craft. Compare against the retained best and untouched original. Revise consequential findings and keep the best reviewed version.

A companion, running locally.

Codex provides research, built-in image generation and design judgment. VectorCraft provides live text, native paths, rendering and export. The companion adds workflow enforcement and evidence while preserving native MCP tools, resources, prompts and instructions.

This website is static documentation and a showcase. It does not host the MCP or edit your artwork. No engine binaries, upstream branding assets or font files are bundled.

Experimental v3.1.0-alpha.1: software checks, independent comparisons and the owner’s anonymous selection are recorded. These examples do not establish general professional superiority. Read the limitations before installing.
