Install the companion.
Keep your local engine.

VectorCraft’s CLI and desktop are installed separately. The gateway and two skills connect them to your local Codex project.

Prepare the checkout

Use a permanent folder. The documented local engine version is VectorCraft 0.9; other versions and operating systems remain unverified. Ordinary web ChatGPT is outside the supported scope.

Download the alpha source and editable examples · SHA256SUMS · Release notes. Verify the checksum before extracting into a permanent folder.

py -3.13 scripts/test_suite.py --unit-only
py -3.13 scripts/install.py --cli 'C:\Apps\VectorCraft\vectorcraft-cli.exe' --desktop 'C:\Apps\VectorCraft\vectorcraft.exe' --vault 'C:\Design Brain' --dry-run
py -3.13 scripts/install.py --cli 'C:\Apps\VectorCraft\vectorcraft-cli.exe' --desktop 'C:\Apps\VectorCraft\vectorcraft.exe' --vault 'C:\Design Brain'

Replace the paths with your actual executables and vault. --codex-home overrides CODEX_HOME and the current user’s .codex folder. Explicit executable arguments or environment variables are preferred; configured manifests, adjacent executable discovery, PATH and supported Windows locations are also recognized.

Verify a fresh connection

Reconnect MCP or begin a fresh Codex chat. Request a substantial design: Studio should activate with designer-v1, calibration, concept review and construction study. A small explicitly scoped edit should use quick mode without unnecessary research.

Current connections retain their startup environment and tool catalog. Keep the checkout in place. Use workflow_status for authoritative schemas, knowledge-vault path and run integrity.

Undo an installation safely

py -3.13 scripts/install.py --rollback --snapshot SNAPSHOT_ID --dry-run
py -3.13 scripts/install.py --rollback --snapshot SNAPSHOT_ID

Snapshots are private under .local/install-snapshots. The installer changes only VectorCraft’s MCP section and managed files in both owned skills. Rollback preserves unrelated later settings and detects modified owned files before writing. There is no force-overwrite shortcut.
