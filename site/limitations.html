Judgment still matters.

The gateway can bind a render to a document revision. It cannot prove that an agent looked at it or that the drawing is good.

What is checked

EvidenceWhat it establishes
Fixture and installer testsPrerequisites, invalidation, compatibility, path discovery and owned-section rollback behavior.
Local Windows integrationActual MCP passthrough, native rendering/reopening, desktop ownership and recovery against the documented installed engine.
Observed independent reviewsVisible region-specific judgments about communication, copy, composition and craft—not universal taste or a human user study.
ChecksumsUnchanged file bytes. They do not establish perception, originality or aesthetic quality.

Remaining limits

The initial supported host is local Codex on Windows with Python 3.13 and the documented VectorCraft version. No separate API model or engine is bundled. Image generation and reviewer availability depend on the host.

Case studies are creator-authored comparisons, not randomized independent-agent trials. Reference coverage and inaccessible sources are disclosed. Native reconstruction may reduce generated texture, naturalistic anatomy or subtle shading; meaningful losses must be critiqued rather than hidden.

Hosted CI runs self-contained checks, not the installed Windows engine or aesthetic reviews. Public evidence uses relative paths and is an explicitly sanitized derivative. Private configuration, raw vault contents, backups and local historical run records are excluded.

Preserve the best version

The candidate, retained best and original are compared under the same brief. Three correction rounds are available; stop after two non-improving rounds. An original may be the final winner. If the visual launch gate fails, preserve the strongest artwork and report the failure.

VectorCraft Studio is an unofficial community companion. No maintainer proposal has been sent and no official status is claimed.
