What happens behind each image?

Codex plans and inspects. The gateway checks task state and revisions. VectorCraft edits native objects and renders previews. Fresh reviewer contexts assess communication and craft at the required gates.

Brief → research → concepts → native roughs where enabled → composition → typography → imagery → finishing → review and correction → verified delivery

Saving a capture, passing a task, accepting a stage, passing final review, and verifying exports are separate decisions. The same image may appear across stages when a stage accepts existing work.

Workflow development

Give the same model a clearer job.

We have changed the workflow around the model: what it receives, how much it edits at once, and what must be checked. We have not trained new model weights. These controls are implemented; their overall quality benefit is still being evaluated.

Standard

Research, concepts and construction studies → stage batches → independent final review.

The baseline already inspects images and supports corrections.

Focused build adds

Current packet → one small task → capture → task decision.

Passing a task does not automatically accept its stage.

Layout first adds

Three isolated native roughs → image comparison → concept selection.

Expose placement and interaction problems before detailed construction.

Full process combines

Native roughs + focused tasks + named parts and their connections.

Check relationships such as hand → handle → tool tip → tyre.

One focused construction loop

  1. 1. ReceiveCodex reads current task, objects, image and findings.
  2. 2. PlanGateway checks task state and document revision.
  3. 3. EditVectorCraft changes native objects.
  4. 4. CaptureSave full and intended-size evidence.
  5. 5. InspectCodex observes the task, neighbors and whole scene.
  6. 6. DecidePass the task, revise it, or report a block.

Revise → preserve this evidence and plan a correction. Task pass → continue until explicit stage acceptance. Final gate → fresh independent reviewers, retained-best comparison, then native/export verification.
